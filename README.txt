MY LITERARY JOURNEY - WEBSITE
==================================

This website uses only HTML and CSS. No JavaScript, libraries,
or animations are required.

HOW TO OPEN
1. Unzip the folder.
2. Double-click index.html to open it in a browser.
3. To edit it, open the folder in VS Code.

FILES
- index.html   : all website sections and writing
- style.css    : colors, fonts, spacing, and mobile layout
- assets/      : the three photos supplied for this portfolio

HOW TO CHANGE THINGS
- To change text, open index.html and edit the text between HTML tags.
- To change colors, open style.css and find the color values (#... ).
- Click an analysis title in the browser to expand or collapse it.
- To replace photos, add your own image files and update the src paths.
- The nav links go to different sections of the same page.

SECTIONS INCLUDED
1. Student Profile
2. Complete Seven Literary Analyses
3. My Favorite Literary Masterpiece: The Odyssey
4. Summary of Learning
5. Personal Reflection
